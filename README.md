# Seesky Glasses Instruction

Sky One 智能眼镜中文使用指南网站。

网站内容包括：

- 三分钟快速上手
- 菜单键与确认键说明
- AI Camera、Photo、Translate、Focus 与 Status 使用流程
- 结果页和绿色显示状态说明
- 常见故障排查与使用注意事项

## 本地运行

需要 Node.js `22.13.0` 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

主要页面代码位于 `app/page.tsx`，全局样式位于 `app/globals.css`。
